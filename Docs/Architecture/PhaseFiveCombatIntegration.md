# 第五阶段：工业科幻美术接入实际战斗

## 入口与范围

新关卡为 `Assets/Defend/Content/Scenes/Dev/IndustrialDefense.unity`。打开后直接播放，准备阶段建设并开始波次。使用第四阶段的能源、波次和建筑配置，初始六栋建筑、840 资金、八波流程均保留。旧关卡与美术展示场景继续保留。

实际战斗 Prefab 位于 `Assets/Defend/Content/PhaseFiveCombat`。六种建筑使用美术交付的模型扩展，普通、快速、重装敌人分别使用独立对象池和最终尺寸。环境采用交付的岩块、入口与工业地面模块。默认镜头放大到 0.55，血条和能量条不投射阴影，操作界面沿用已保存的 59 个对象。

## 结果与表现的连接

`GameWorld.Events` 保存当前逻辑步已经结算的受击、死亡、损毁、维修、护盾受击与破裂结果。`Energy.Departures` 和 `Energy.Deliveries` 保存已经发送或已经完成到货的每一跳快照。集合只读，下一逻辑步清空，均不包含 Unity 对象。新增记录不改变伤害、费用、寻路、预约或能源结算顺序。

`GameSessionRoot` 在每个逻辑步后同步视图并调用 `CombatArtPresentation.ObserveStep`，所以一帧推进多个逻辑步也不会遗漏中间事件。渲染刷新不会重新播放同一步。枪口、射线和命中沿用真实 `ShotSnapshot`；范围冲击环读取该次攻击的真实半径。重装接触反馈只在 `LastAttackTick` 对应的实际出手发生。

`CombatModelAnchors` 预先绑定炮塔旋转、炮口、能源端口和状态挂点。连射炮交替使用两个炮口，重击炮使用后坐枢轴。敌人保留交付尺寸与材质，机械腿步态由表现位移驱动。

## 时间与生命周期

- 特效池关闭自己的自动计时，统一使用逻辑时间及其渲染插值。暂停同时冻结粒子、机械动作和在途脉冲；倍速跟随模拟速度。
- 能源脉冲时长为真实到达步减去发送步。目标移动、出售或被毁取消在途效果；收到 `Deliveries` 才能播放到货闪光。仅有预约不会触发到货。
- 死亡和建筑损毁效果不借用即将回收的主体，避免展示场景的恢复动作把敌人复活。建筑的持续损毁姿态由存活状态控制，维修后恢复。
- 状态效果按位置快照刷新；重装搜索继续显示所知旧位置。失效、移动、出售与重开清理旧句柄。
- 重开先停止全部特效，再重建世界和回收敌人；恢复炮塔旋转与损毁缩放，清空事件序号。界面不重新实例化。
- 结局停止常驻状态和运输；最后一次爆炸可自然结束。主动暂停仍冻结这些尾部效果。

## 预算与降级

继续使用美术库上限：短效果 64 组、碎片 128 个、运输 128 个、状态 32 组。能源发送和到货端口装饰只使用最多一半短效果容量，为枪口、命中和护盾留出空间。省略装饰不改变真实到货、运输与伤害。

状态优先级为重装目标、选中建筑问题、其他供电问题、反应堆与中继运行；同类目标汇总，数量超限时省略低优先级状态。场景中保留能源连接和选择范围，实际脉冲替换旧运输方块，实际战斗效果替换旧射击折线与目标几何。

## 制作与检查

菜单“涌现防线 / 创建或打开工业防线关卡”只在缺少时制作；已有场景直接打开，不覆盖后续手工调整。制作工具为 `PhaseFiveCombatSceneBuilder`。

`Tools/Unity/PhaseFiveCombatValidation.cs` 提供场景引用、正常播放诊断、100 建筑 / 200 敌人单步集成检查与近景渲染。`PhaseFiveCombatProbe` 仅在开发构建显式传入 `-phase-five-combat-smoke`，或编辑器检查显式创建时运行，所有诊断配置只在内存存在。正常游戏不运行探针、不自动建设。

最终证据和检查边界见 `Docs/Validation/PhaseFiveCombatReport.md`。

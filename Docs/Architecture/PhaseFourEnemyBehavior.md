# 第四阶段：重装敌人与能源攻防

日期：2026-10-10。用户已确认按局部感知、重装负责能源破坏、优先攻击附近暴露设施的方向设计并由开发团队完成。本文为实施合同；验证结果另记于 `Docs/Validation/PhaseFourReport.md`。

## 目标与交付

让供电设施的位置、备用线路、炮塔布置和维修资金影响战局。普通与快速敌人维持核心推进，重装敌人能够在核心道路畅通时转向有价值的能源设施，也可以压制局部高威胁炮塔。信息不足时采用保守判断，不计算全地图最佳断电节点。

新增独立的第四阶段配置与关卡入口，从双隘防线现有资产复制并定向绑定。保留第三阶段关卡、原始参数和旧验收记录。功能通过战斗配置启用，旧配置默认关闭，方便回归对照。第四阶段继续使用八波双入口及现有建筑、敌人，不增加新的怪物种类、资源或异常状态。

## 已确认边界

- 纯 C# Simulation 决定位置、目标、伤害与能源；Unity 仅负责配置、输入、表现。
- 上限为 100 栋未出售建筑（含损毁建筑）和 200 个存活敌人。敌人继续允许重叠。
- 核心唯一，不可移动或出售；核心死亡立即锁定失败。
- 能源跨波持续，预约不是实际到货。中继损毁不清空其他建筑的缓存，不添加人工断电效果。
- 维修即时付费；波末不自动修复或补盾。普通维修不重置敌人攻击冷却或目标保持计时。
- 全部 UI 完整保存在场景或 Prefab，运行时只绑定、更新、显隐；标记使用预存非 UI 几何。
- 不修改包、全局渲染或其他项目设置，不提交或推送，不执行哈希值校验。
- 第二阶段已结束的长时间验收不重启；第四阶段执行针对性测试、完整逻辑回归、短运行与构建验证。

## 感知与目标保持

核心位置是已知任务目标。其他建筑按距离感应，不增加视觉遮挡系统；岩体仍阻挡移动，不阻挡能源。建筑距离以占地边界计算，感应不能通过全图供电诊断泄露不可见设施。

初值：感应半径 8 格、观测记忆 3 秒、评估间隔 0.5 秒、目标至少保持 3 秒；新目标收益须达到旧目标的 1.35 倍才主动切换。相同分数按稳定建筑身份决定。所有时间使用模拟时间，暂停冻结。

局部观测仅采集感应范围内的建筑和两端均可感知的连接；火力使用短时间内实际发生的伤害或开火记录，能源使用实际完成传输的记录。不得读取玩家优先级作为仇恨、未来预约作为到货，或借远端拓扑算出隐藏节点价值。未观测的备用线路不等于不存在。

每个重装敌人拥有自己的有限记忆。刚进入范围不回溯获知其进入前全部战斗历史。目标移出感应范围后只保留最后已知位置，最多按记忆时长搜索；再次发现前不得跟随其新位置。建筑损毁、出售、生命代次变化或接近路线失效时解除旧攻击目标。目标还存活但普通维修不解除目标保持。

## 选择规则

1. 普通与快速敌人沿用核心推进及封路拆障。
2. 重装已经进入核心攻击范围时优先攻击核心。
3. 其他情况下，最多详细比较 6 个附近候选，排除损毁、出售、岩体以及没有可达攻击位置的目标。
4. 中继与反应堆的价值来自局部有效供给、连接的活跃炮塔、能观察到的替代供给。空置且无有效供给关系的设施不因建筑种类自动成为目标。
5. 炮塔价值来自近期局部实际火力。停止射击一瞬间不立即清零威胁；长期停火后自然衰减。
6. 对候选扣除接近所需时间、按当前敌人伤害和目标耐久估计的拆毁时间、路径经过的已观测火力覆盖。比较依据保持为局部启发式，不声称预测战斗最优解。
7. 相对继续向核心推进，战略绕行增加的路程初限 6 格。首版不为战略设施连续拆多栋建筑；没有合适目标则回到核心推进，完全封路时复用旧拆障规则。
8. 不进行敌群指挥、全图目标分配或根据玩家未暴露布局调整策略。重装之间可以自然攻击同一设施。

首版最终评分如下。所有实际活动仅取最近 3 秒，按 `exp(-事件年龄 / 3秒)` 衰减；时间窗口到期即删除。伤害率、供给率均将窗口内加权量除以 3 秒，供给换算为能量点（1000 小单位为 1 点）。

- 炮塔收益 = `3 × sqrt(观测伤害率)`。
- 能源设施收益 = `10 × sqrt(观测实际向外供给率) + 2 × sqrt(所支持炮塔的观测伤害率)`。没有观测到实际向外供给时收益为零。
- 所支持的炮塔仅沿已观测到的关系检查至多两跳；每座炮塔的伤害贡献乘以“依赖此设施的观测入站路线数 / 全部观测入站路线数”。多条路线若共同依赖同一源头，不会被当作替代该源头的独立供给。这是局部近似，不保证未观测到的替代线路不存在。
- 成本 = `2 + 接近秒数 + 预计拆毁秒数 + 20 × 路径预期伤害 / 敌人最大生命`。路径预期伤害仅根据已观察到的炮塔伤害率和路径在射程内的时间累加。
- 分数 = `收益 / 成本`。分数须大于 1 才值得偏离核心；主动更换目标须达到 `max(1, 当前分数) × 1.35`，并满足至少 3 秒的目标保持要求。

最多 6 个候选包括当前目标。先用接近距离和拆毁时间粗排，再用预算内可取得的共享路径详细评分。当前目标失效时不受主动更换的保持时间约束。普通维修只影响后续耐久估计，不重置保持时间和攻击冷却。

## 导航与工作预算

保留现有共享四邻域导航作为核心推进的基础。战略目标增加按目标建筑和占地版本缓存的距离场；多个敌人共享同一目标路径，不为每个敌人每步搜索全图。记忆位置的搜索不得借用建筑的新位置。

每逻辑步最多执行 20 次完整目标评估、最多新建 2 个战略目标距离场，按稳定敌人顺序轮转，防止队尾饥饿。距离场缓存上限 128 项；占地版本变化使旧路径失效。预算不足时保留仍有效的行动或暂时继续核心推进，保留内部目标和原保持时间，不能使用未完成的路径结果或在连续拓扑变化时僵住。占地变化立即禁止走入新障碍；耐久和优先级变化不重建几何距离场。

路径成本评估以可行四邻域路径为基础，首版不额外构建全图最安全路线。记录实际评估次数、战略路径构建次数、延期次数及目标切换次数，以便在数量上限下验收。

## 模块与团队接口

模拟负责人拥有 `Assets/Defend/Scripts/Simulation`，负责行为、导航、局部观测和预算。

- 新增不可变 `EnemyBehaviorSettings`，构造参数使用规范完整名称，默认禁用；`BattleSettings` 末尾追加可选参数 `enemyBehavior`，公开 `EnemyBehavior` 属性。
- 默认参数：`enabled=false`、`sensingRadius=8`、`observationMemorySeconds=3`、`evaluationIntervalSeconds=0.5`、`minimumTargetLockSeconds=3`、`switchScoreRatio=1.35`、`maximumCandidates=6`、`maximumEvaluationsPerTick=20`、`maximumPathBuildsPerTick=2`、`maximumAdditionalTravelCells=6`。
- `EnemyState` 公开只读 `TargetPurpose`、`TargetX`、`TargetZ`、`LastAttackTick`；保留 `TargetBuildingId`。`EnemyTargetPurpose` 包含 `AdvanceToCore`、`ClearObstacle`、`DisruptEnergy`、`SuppressTurret`、`SearchLastKnownPosition`。
- `TargetX/TargetZ` 为当前行动的已知目标位置；表现不得自行读取隐藏位置替代它。
- `BattleSystem` 提供只读行为统计，具体统计类型由模拟负责人与测试负责人协商。

表现负责人拥有 `Scripts/Unity/Authoring/BattleSettingsAsset.cs`、`Scripts/Unity/Presentation`、`Scripts/Unity/UI/BattleControlPanel.cs` 和新增的第四阶段 Editor 制作代码；不编辑 Simulation 或现有场景制作器。通过定向复制与绑定创建第四阶段关卡、配置、敌人 Prefab、面板及标记。

测试负责人拥有新增第四阶段 EditMode 测试和 `Tools/Unity/PhaseFourValidation.cs`；不编辑生产 Simulation、表现或既有测试来掩盖回归。

主负责人拥有本设计、集成验证脚本、构建/打包、报告及上下文更新。只有主负责人操作 Unity Editor、进入播放或触发构建，避免多人改变 Editor 状态。

## 玩家反馈

- 八波预告复用现有说明区域，明确能源破坏重装从哪侧出现及应对提示；不在无重装的波次制造误报。
- 重装目标上显示预存几何标记，必要时用有限数量的预存连线显示接近方向；不能在 200 敌人时产生难以辨认的全屏线条。
- 选中建筑显示正在以它为目标的重装数量和行为说明；目标记忆搜索应与实际攻击区分。
- 重装接近、朝向与攻击反馈从模拟状态更新，攻击动作与实际伤害时刻一致，池化重用与重开清理状态。
- 攻击反馈读取实际出手时保存的目标身份与位置。建筑移动后，旧攻击闪光不会转移到新位置。
- 说明中明确：摧毁中继可能降低供给，炮塔缓存仍会继续使用；提高优先级只改变能源份额，不改变当前最近目标射击规则。

## 验收矩阵

1. 核心道路畅通时，重装攻击有局部供给价值的能源设施，普通与快速继续推进；无价值诱饵不会无限吸引。
2. 远处未感知的设施变化不立刻改变决定；每个敌人的感知独立，短暂断流不抖动，目标保持与更换阈值可验证。
3. 有限绕行、不可达候选、岩体、多格建筑、完全封路、目标移动/出售/损毁/修复、最后已知位置和记忆过期均有行为覆盖。
4. 普通维修不重置攻击冷却；核心临近优先、核心致死立即停止后续攻击；暂停、重开、跨波状态边界保持正确。
5. 比较同预算单一供电、独立备用线路、保护节点布局。记录到货、缺能等待、设施损毁、维修开支及核心损伤；不要求所有布局胜利，也不以脚本强制断电替代真实运输。
6. 原 77 项测试完整回归；不禁用旧测试。新增测试以可见行为和普通世界命令为准。
7. 100 栋/200 敌人短边界检查：工作预算、稳定推进、目标响应、能源守恒和耗时分位；直接比较字段、计数、集合与对象身份。
8. Unity 编译、序列化引用、UI 预存、场景重开、标记状态、Windows 构建和短运行验证。可见画面、后台运行及纯模拟证据分别记录，不以任何一种代替其他证据。

# 涌现防线：能源防线试玩说明

第四阶段使用 Unity 6000.6.5f1。Windows 开发程序位于 `Builds/PhaseFour/Defend.exe`，双击同目录 `Start-Defend.cmd` 启动。分发时保留整个文件夹。验证范围以 `Docs/Validation/PhaseFourReport.md` 为准。

## 这次的变化

普通和快速敌人继续向核心推进。重装敌人会观察附近的射击和能量传输，寻找值得攻击的中继、反应堆或炮塔。它们有感应距离和短时记忆，不掌握整个地图的供电结构，也不会因为短暂断流立即更换目标。

重装锁定设施后会保持目标一段时间；附近收益更高的目标、设施损毁或失去接近路线可能使它改变行动。移出感应范围的建筑只留下最后已知位置，敌人不会无限追踪。进入核心攻击范围后，重装会直接攻击核心。

## 怎样应对

- 把重要中继放在炮塔能够覆盖其接近路线的位置。
- 建立独立备用线路。两条线路如果仍依赖同一个中继，就没有消除这个共同弱点。
- 选中受威胁的设施，观察重装数量、实际到货和储能。
- 为负责拦截的炮塔分配足够能源，并保留维修资金。提高能源优先级不改变炮塔攻击最近敌人的规则。
- 中继损毁后，炮塔仍会消耗已有缓存；供电恢复也不代表缓存立即补满。预约供给不能用于提前开火。

紫色方框表示重装锁定的位置，红色反馈对应实际出手，琥珀色十字表示搜索最后已知位置。标记按目标汇总，多个敌人攻击同一设施时不重复绘制大量连线。波次说明会提示有重装的来袭方向。

## 基本操作和规则

目标是在八波双入口进攻中守住核心。初始六栋建筑已扣除费用，剩余 840 资金。准备期间能源仍会运行，可以等待炮塔充能后再开波。

- 左键选择建筑或确认放置；右键、Esc 或取消按钮退出建造。
- 滚轮缩放，中键拖动；空格或暂停按钮暂停和继续。
- 暂停时提交的命令排队，继续后执行。
- 选中建筑可调整供能优先级、移动、维修或出售。移动会损失无法送达旧位置的在途能量。
- 核心唯一，不能移动或出售；核心死亡即失败。
- 维修即时付费，波末不自动修复、补盾或重置能源。
- 建筑与岩体阻挡敌人移动，敌人之间仍可重叠；炮塔射击和能源传输不检查遮挡。
- 重新开始恢复场景保存的初始布局。当前没有存档功能。

| 内容 | 路径 |

| 目标标记 | `Assets/Defend/Content/Prefabs/VFX/EnemyTargetMarker.prefab` |

菜单“涌现防线 / 创建或打开能源防线关卡”首次从已保存的第三阶段场景复制；已有第四阶段场景再次打开不会覆盖手工内容。建筑定义与建筑外观继续复用第三阶段资产。修改这些共用资产也会影响第三阶段，需要修改阶段独立参数时应先复制并定向绑定。

所有界面均预先保存在场景或 Prefab 中。敌人数量上限为 200，未出售建筑上限为 100（包含损毁建筑）。本版本仍为白盒开发包，数值与策略平衡需要继续通过实际游玩调整。

## 验证入口

纯模拟和资源检查由 `Tools/Unity/PhaseFourValidation.cs` 提供；新增 EditMode 测试与原测试一起运行。设计及确切参数见 `Docs/Architecture/PhaseFourEnemyBehavior.md`。

独立程序只有显式传入 `-phase-four-smoke -phase-four-output <目录>` 才启用短运行探针。该模式用运行时配置副本把重装放在防线附近，并提高耐久，检查目标、设施伤害、暂停和重开；它不修改保存的关卡，也不作为正常关卡平衡、完整八波通关或可见窗口帧率证据。普通双击启动不会自动建设或自动开波。

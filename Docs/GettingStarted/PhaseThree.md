# 涌现防线：双隘防线试玩说明

使用 Unity 6000.6.5f1。Windows 程序为 `Builds/PhaseThree/Defend.exe`，也可双击同目录 `Start-Defend.cmd`。分发时保留整个文件夹。

## 开始游玩

目标是在八波进攻中守住核心。关卡有西侧南、北两个入口，岩体把敌人引向两条通道。初始有六栋建筑，扣除建造费用后剩 840 资金。先部署并等待充能，再点击“开始第一波”；每波清场获得资金，下一波由玩家主动开始。两套自动建设顺序的模拟时长约 12–14 分钟，自由规划时间另计。

- 左键选择建筑或确认放置；右键、Esc 或“取消放置”退出建造。连续购买保留同类建筑选择。
- 滚轮缩放，中键拖动。镜头相对水平面向下 70°，保持正交投影。
- 空格或“暂停”暂停/继续。暂停期间提交的建造、维修等命令排队，继续后生效。
- 建造预览绿色表示可放置，红色表示位置、资金或数量条件不满足。圆环表示传输范围或攻击射程。
- 选中建筑后，亮线显示其直接供电连接；右侧查看储能、预约、实际到货、耐久和攻击数据。
- 波末不会自动维修或补盾。维修即时付费；移动可能损失发往旧位置的在途能量。
- 核心不能移动、出售或再买一座，死亡后本局结束。重新开始恢复场景中保存的初始布局。

## 怎样选择炮塔

| 类型 | 价格 | 能源与攻击特点 | 适用情况 |
| --- | ---: | --- | --- |
| 连射炮 | 140 | 每 0.3 秒消耗 1.2 能量，18 伤害，7 格射程 | 便宜、单发门槛低，拦截快速敌人 |
| 重击炮 | 230 | 每 2 秒消耗 8 能量，130 伤害，9 格射程 | 对重装敌人集中输出，注意提前充能 |
| 范围炮 | 240 | 每 1.6 秒消耗 6 能量，命中点 2.4 格范围内造成 42 伤害 | 通道中的密集敌群 |

普通敌人为红色；快速敌人为黄色、体型较小；重装敌人为紫色、体型较大。敌人可以重叠，攻击不检查建筑遮挡；岩体不能拆除。封死道路时，敌人会攻击可接近的阻挡建筑。能源传输不受岩体遮挡。

## 怎样排查缺能

1. **线路中断**：先检查范围和受损建筑，确保能追溯到存活的反应堆。
2. **中继拥堵**：中继内部已有实际滞留的能量。缩短线路，增加另一条可用供电路径，或减少同一中继承担的需求。
3. **发电不足风险**：面板按所有相关炮塔持续满速攻击估算需求，用于提前判断压力；实际情况还受传输损耗、核心护盾消耗和敌人是否进入射程影响。
4. **等待充能**：炮塔已有目标，但缓存还不足以支付下一发。已预约供给尚不能用于开火。

“最近一秒到货”是上一个完整模拟秒的实际到货量，“累计实际到货”是本局已进入建筑的能量；两者都不包含预约。反应堆产生能量，不是接收到货，所以其到货为零是正常现象。优先级提高可以争取更多有效供给，但不会创造额外能源。

## 两种已经验证的建设思路

坐标以网格的 `(X,Z)` 表示，供复现和 Editor 布局参考。两种策略都使用普通关卡资金，不开启压力参数。

| 开始波次前 | 集中防御 | 前沿分区防御 |
| --- | --- | --- |
| 1 | 范围炮(22,18)、重击炮(25,21)、反应堆(29,24) | 反应堆(17,12)、范围炮(16,10)、重击炮(18,13) |
| 2 | 范围炮(22,23) | 反应堆(17,28)、连射炮(17,30) |
| 3 | 重击炮(23,19)、中继器(23,21) | 重击炮(16,13) |
| 4 | 连射炮(21,24)、反应堆(21,21) | 范围炮(16,29)、中继器(21,26) |
| 5 | 重击炮(23,23)、中继器(25,25) | 重击炮(18,27)、中继器(21,14) |
| 6 | 范围炮(20,18)、连射炮(21,17) | 范围炮(20,12)、反应堆(21,19) |
| 7 | 重击炮(21,26)、反应堆(22,26) | 连射炮(18,10)、重击炮(20,28) |
| 8 | 范围炮(20,24)、连射炮(22,16) | 范围炮(20,26)、连射炮(20,15) |

每次扩建后约等五秒再开波；有受损建筑时按资金情况付费维修。集中布局便于共享供电，前沿布局可以更早接敌，但需要为两侧分别供能。它们是可复现的示例，不要求玩家照表施工。只守着初始布局、不继续建设，在自动模拟中于第四波失败。

## 编辑工程

以下路径以 `Assets/Defend` 为根。制作菜单为“涌现防线 / 创建或打开双隘防线关卡”；已有场景再次打开会保留手工修改。

| 内容 | 编辑入口 |
| --- | --- |
| 关卡场景、镜头、初始布局 | `Content/Scenes/Dev/TwinPassDefense.unity` |
| 主界面、选中面板、结算 | `Content/Prefabs/UI/PhaseThreePanel.prefab` |
| 建筑价格、容量、供电与耐久 | `Content/Definitions/PhaseThree/*.asset` |
| 八波、敌人组合、炮塔攻击、入口、岩体 | `Content/Definitions/PhaseThree/TwinPassBattleSettings.asset` |
| 地图大小、初始资金、损耗 | `Content/Definitions/PhaseThree/TwinPassEnergySettings.asset` |
| 建筑外观 | `Content/Prefabs/PhaseThree` |
| 敌人外观、几何血量条 | `Content/Prefabs/Enemies/PhaseThreeEnemy.prefab` |

编辑初始建筑位置时，同时维护 `WorldPresentation.Authored Buildings` 列表；初始建筑仍需支付购买费。修改岩体格配置时，同步调整场景“岩体 X,Z”几何；几何只负责显示，配置决定实际不可通行格。两个入口也应同步调整场景标记。所有 UI 预先保存在 Prefab/场景中，不能靠运行时代码补建。

当前上限为 100 栋未出售建筑（包括损毁建筑）和 200 个存活敌人。本阶段没有存档、多地图、科技树、音效或正式美术。验证范围与机器性能数据见 `Docs/Validation/PhaseThreeReport.md`。
